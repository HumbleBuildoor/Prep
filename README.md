# Prep

An offline web app for tracking household emergency supplies: what you have, when it is due, and how many days it lasts in each scenario.

- **Supplies** in eight areas: water, food, cooking fuel, power, medical, hygiene, pets, kit and documents.
- **Scenarios** (water cut, power cut, flood, leaving with the bags, shops closed, everything off). Each one counts only what is usable under its conditions and shows the need that runs out first.
- **Due** dates: best-before, expiry, and check or recharge intervals in one list.
- **Log** of every add, use, restock, edit and check.
- **Photos** of each item, and optional label reading by Claude with your own Anthropic API key.

## Where the data lives

Everything is stored in the browser on the device (IndexedDB). There is no server, no account and no analytics. This repository contains code only.

The one outside connection is optional: if you save an Anthropic API key under More and tap **Read label**, the photos and the key are sent to `api.anthropic.com`. The key is stored on the device and is left out of backup files.

Back up from **More → Save a backup file**. The same file restores or moves the data to another device; importing merges, it never deletes.

## Run it

It is a static site with no build step.

```bash
python3 -m http.server 8000      # then open http://localhost:8000
```

To install it on a phone it must be served over HTTPS, for example with GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder). Open the address in Chrome on Android and choose **Install app** or **Add to Home screen**. After the first load it works with no connection.

## After changing any file

```bash
python3 tools/stamp.py           # rebuilds sw.js so installed copies pick up the update
npm test                         # unit tests for the calculations (Node 22)
```

## Layout

| Path | What it is |
|---|---|
| `js/calc.js` | Dates, status and the scenario engine. Pure functions, unit-tested. |
| `js/defaults.js` | Areas, templates, starting settings, preset scenarios and the sources of the default figures. |
| `js/db.js` | Storage. Quantities follow an append-only log, so two copies can be merged later. |
| `js/reader.js` | Label reading through the Claude API. |
| `js/app.js` | Views and dialogs. |
| `sw.js` | Service worker for offline use. Generated by `tools/stamp.py`. |
